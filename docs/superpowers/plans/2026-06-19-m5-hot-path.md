**Goal:** Build the agent-egress hot path end to end — an agent posts a raw 402 to
`POST /v1/payment/authorize`; agentOps parses it server-side into a typed quote, evaluates SpendPolicy
deny-by-default against hold-inclusive windows, claims the grant, places a reserve hold, signs an
EIP-3009 authorization via KMS (verify-before-submit), and returns the `X-PAYMENT` header (ALLOW) or a
structured `403 {reason}` (DENY). The signature-leaves-custody moment is BROADCASTING; an EXPIRY_CHECK
reconciler resolves the hold to SETTLED/EXPIRED on on-chain confirmation only.

**Architecture (Phase-1 Oracle model).** agentOps SIGNS ONLY; it does not broadcast — custody of the
signed header transfers to the agent at the `authorize()` response (BROADCASTING boundary, BUG-41).
Settlement happens when the agent submits the authorization; agentOps reaches SETTLED/EXPIRED via
EXPIRY_CHECK (on-chain nonce-consumption read), never on a network condition alone (BUG-20/26/42). All
on-chain reads sit behind seams (`TokenDomainSource`, `NonceReconciler`) so the entire path is
Testcontainers-testable now; the viem-backed Arc-testnet implementations drop in behind those seams in
L8 (the only credentials-gated chunk).

**Tech Stack:** Fastify (`app.inject`) · pg · ioredis + Lua (`defineCommand`/EVALSHA) · viem
(EIP-712 sign + recover) · zod (body validation) · Vitest + Testcontainers.

## Canonical behaviors (cited; adopt verbatim)
- **E2 parse + rail detect.** `accepts.extra.name=="GatewayWalletBatched"` → circle-nano else raw
  x402; `resource_id = accepts.resource` (x402-spec field, NOT a reconstructed URL); fail-closed on
  malformed/unknown rail/missing `verifyingContract|domain`: `engine-specs-FINAL.md:101-104,111`,
  `policy-engine-FINAL.md:98-114`.
- **Dual-rail validBefore.** raw x402 = `now + accepts.maxTimeoutSeconds`; circle-nano = `now + 3d`
  (Gateway hard minimum): `policy-engine-FINAL.md:200-207`.
- **E3 P3-A ordered checks, deny-by-default.** RailPermission → ServiceScope (destination/resource
  allowlist) → VelocityLimit → SpendCap (≤ cap, **EVERY window**) → per_transaction_max; any miss →
  reason_code, reject: `policy-engine-FINAL.md:103-109`, `engine-specs-FINAL.md:127`.
- **Hold-inclusive utilization.** committed = SETTLED + outstanding holds (RESERVED/SIGNED/
  BROADCASTING), never settled-only: `engine-specs-FINAL.md:127`, `policy-engine-FINAL.md:234-239`
  (already implemented in E4 `windowSum`).
- **Capture-at-entry.** Read `effective_policy@version`, capture `policy_version` at the start of the
  critical section; all checks use that snapshot: `policy-engine-FINAL.md:104`, `engine-specs:126`.
- **Grant claim.** Atomic NX on `(payment_id, resource_id)` in the global store BEFORE RESERVED;
  already-claimed → deduped, NO 2nd grant; TTL = this payment's validBefore delta:
  `policy-engine-FINAL.md:116-120` (already implemented in E4 `claimGrant`).
- **P3-B allocation (BUG-19/36).** First gate: `org:{id}:deny_all` set → DENY `ORG_SUSPENDED`. Then
  ATOMICALLY reserve before checks: `available = total_budget − allocation_committed −
  allocation_reserved`; `requested > available` → `TOTAL_BUDGET_EXCEEDED`; else INCR
  allocation_reserved (finality-timeout TTL). Only on PROCEED check per_agent_max / cooldown /
  allowed_destinations (own agents only) / sibling_quota: `engine-specs-FINAL.md:128`,
  `policy-engine-FINAL.md:253-262`.
- **Signing (E6).** raw x402: domain via EIP-5267 ladder; circle-nano: `GatewayWalletBatched`/`1`,
  `verifyingContract` from `accepts.extra` (never hardcode). Local verify-before-submit (BUG-27): sign
  → recover → only then return: `policy-engine-FINAL.md:189-208`, `engine-specs-FINAL.md:201`. Raw
  signature bytes never logged: `policy-engine-FINAL.md:210`.
- **BROADCASTING + EXPIRY_CHECK.** State flips to BROADCASTING at `authorize()` response; hold is then
  permanent until on-chain resolution. EXPIRY_CHECK: nonce consumed → force-SETTLED; unspent →
  EXPIRED (release); RPC unavailable → hold stays LOCKED, operator alert, NO auto-release:
  `policy-engine-FINAL.md:122-157,166-176`, `engine-specs-FINAL.md:129,284`.
- **E9 authN.** Resolve `ag_live_…` (hashed, constant-time) → `{agent_id, org_id}`; tenant-bind
  (`WHERE org_id=?`); **reject admin `sk_`**; replay guard (nonce + timestamp/idempotency); ALLOW →
  `200 {X-PAYMENT}` / DENY → `403 {reason}`: `engine-specs-FINAL.md:226-230,279,296`.
- **Fail-closed.** Resolution no quote → no spend; Enforcement deny-on-doubt; Redis unreachable →
  deny; KMS failure → FAILED_TERMINAL no signature: `engine-specs-FINAL.md:307-314`.

## Implementation choices where the spec is SILENT (flagged, not spec claims)
- **On-chain reads behind seams.** `TokenDomainSource` (already exists) for the EIP-5267 read and a new
  `NonceReconciler` (`wasNonceConsumed(wallet, nonce) → boolean | 'rpc_unavailable'`) for EXPIRY_CHECK.
  Lets L1–L7 be deterministic + Docker-only; the viem-backed Arc-testnet implementations land in L8.
- **X-PAYMENT header = base64url(JSON) of the x402 payment payload** `{x402Version, scheme, network,
  payload:{signature, authorization}}`. Exact field shape confirmed against the x402 skill at L4 before
  the live chunk; the header is opaque to the agent (it submits it verbatim).
- **`paymentId` minted by the Oracle** (`pay_…`, 128-bit) at request entry; it is the FSM key and the
  grant/reserve/audit key. The agent does not supply it (it supplies the raw 402 + request_context).
- **Replay guard = per-agent `(nonce)` SET NX with the request `timestamp` window** in Redis; outside
  the freshness window or a replayed nonce → reject. Idempotency-Key, when supplied, returns the prior
  decision. (The grant-claim NX is the money-replay defense; this is the request-replay defense.)
- **P3-B is built but not agent-egress-triggered.** Its evaluator + `allocation-reserve.lua` ship here
  (the plan anchors `allocation-budget.test.ts` to M5 so both policy classes live under one enforcement
  authority); the `depositFor` trigger is wired in M6. No agent authorize path calls P3-B.
- **DENY writes a `payment_events` audit row** (state matches, result=DENY, reason_code, settlement_ts
  NULL) reusing the E4 cold tier; ALLOW writes the audit row only at SETTLED (via EXPIRY_CHECK), as
  today. This keeps `recordSettlement` untouched and adds a thin `recordDecision` for the DENY/QUOTED
  audit.

## Chunk sequence (TDD)
- [x] **L1 — E2 Resolution: `parse402` → Quote + rail detect (pure).** `parse402(rawBody,
  requestContext, now) → Quote` (throws `ResolutionError` fail-closed). Rail detect by
  `accepts.extra.name`; `resourceId = accepts.resource` (fallback `canonical(method+host+path)`);
  `validBefore` per rail; reject unknown rail / missing `verifyingContract|domain` / malformed
  `accepts`. Test (pure): a circle-nano `accepts` → `{scheme:'circle-nano',chain:'arc'}`,
  validBefore≈now+3d, destination+resourceId bound; a raw-x402 `accepts` → raw rail, validBefore≈
  now+maxTimeoutSeconds; missing verifyingContract → throws; unknown rail name → throws.
- [x] **L2 — E3 P3-A SpendPolicy evaluator (pure, deny-by-default).** `evaluateSpend({policy, amount,
  railScheme, resourceId, windowUtil:Record<window,bigint>, velocityCount}) → {allow:true} |
  {allow:false, reason:DenyReason}`. Ordered: rail not in railPermission → `rail_not_permitted`;
  resourceId not in serviceScope → `service_not_allowed`; velocityCount ≥ limit → `velocity_exceeded`;
  `util+amount > cap` for ANY window → `spend_cap_exceeded`; `amount > perTransactionMax` →
  `per_transaction_max_exceeded`; else allow. Test (pure): clean allow; each deny reason fires in
  order; cap is hold-inclusive (util already counts holds); empty serviceScope denies (deny-by-default).
- [x] **L3 — E3 P3-B AllocationPolicy + `allocation-reserve.lua` (BUG-19).** Keyspace:
  `allocationCommitted`/`allocationReserved` per org. Lua (numberOfKeys 2: committed, reserved):
  `available = total − committed − reserved`; `requested > available` → return 0 (reject); else
  `INCRBY reserved requested`, return 1. `evaluateAllocation(redis, {orgId, agentId, requested,
  policy})`: deny_all set → `org_suspended`; else atomic reserve; on PROCEED check perAgentMax /
  cooldown / allowedDestinations (own-agent fence). Test (Testcontainers redis): reserve within budget
  → allow + reserved bumped; over budget → `allocation_exceeded`, reserved unchanged; deny_all set →
  `org_suspended` first (no reserve); concurrent reserves never oversubscribe `total`.
- [x] **L4 — E6 hot-path signing → X-PAYMENT (verify-before-submit, BUG-27).**
  `signAuthorization({signer, rail, quote, fromAddress, domain}) → {authorization, signature}`: build
  EIP-3009 typed data (validBefore from quote), KMS `signTransfer` (role `agent-float`, op
  `external-spend`), then **recover locally and assert == fromAddress** (throw on mismatch).
  `encodeXPayment(rail, authorization, signature) → string` (base64url x402 payload). Test (local,
  LocalKmsSigner + viem): produced signature recovers to the agent-float address; decoded X-PAYMENT
  round-trips the authorization; a tampered message fails recovery; the returned object/string is
  asserted to contain no field named for raw key material.
- [x] **L5 — E3 orchestrator `enforceSpend` (steps 2-8, hot path).** `enforceSpend(deps, {agent, org,
  quote, fromAddress, paymentId, now}) → {outcome:'ALLOW', paymentId, xPayment} | {outcome:'DENY',
  reason}`. Flow: `deny_all` → `org_suspended`; `resolveEffectivePolicy` (M4, captures epoch+version);
  `snapshotWindows(now)`; read each `windowSum` + velocity; `evaluateSpend`; DENY → `recordDecision`
  audit, return; ALLOW → `claimGrant` NX (already claimed → deduped, NO 2nd reserve); `reserveHold`
  (hold-inclusive); `signAuthorization` (L4) → `encodeXPayment`; return ALLOW (state BROADCASTING).
  Test (Testcontainers pg+redis + LocalKmsSigner): seed org/agent/policy(cap $10)+float; allow path
  reserves + returns header; a replayed `(paymentId,resourceId)` returns deduped with NO second
  reserve (reserved counter unchanged); a $12 spend denies `spend_cap_exceeded` with no hold left.
- [x] **L6 — E9 Oracle `POST /v1/payment/authorize` + authN.** `authenticateAgent(pool, authzHeader)`:
  parse `Bearer ag_live_…`, **reject `sk_`** (→ 401), hashed constant-time lookup → `{agentId, orgId}`
  (tenant-bound). `registerAuthorizeRoute(app)`: zod body `{agent_id, raw_402_body, request_context}`,
  replay guard, `parse402` → `enforceSpend`, map ALLOW → `200 {x_payment}` / DENY → `403 {reason}` /
  auth fail → `401`. Tests (`app.inject`, Testcontainers): allow then a cap-exceeding deny on the same
  agent (`authorize-allow-then-deny`); an `sk_live_` key → 401 (`sk-key-fenced-out`); agent A's key

  captured logs contain no raw signature bytes (`no-raw-sig-bytes`).
- [x] **L7 — EXPIRY_CHECK reconciler.** `NonceReconciler` seam:
  `wasNonceConsumed({wallet, nonce}) → true | false | 'rpc_unavailable'`. `reconcile(deps, payment) →
  'SETTLED' | 'EXPIRED' | 'LOCKED'`: consumed → `settleHold` + `recordSettlement` (force-SETTLED);
  unspent (past validBefore) → `releaseHold` (EXPIRED); `'rpc_unavailable'` → LOCKED, NO state change,
  operator-alert log, NO auto-release. Test (Testcontainers + mock reconciler): consumed → SETTLED,

- [x] **L8 — Arc testnet live wiring (creds-gated).** `src/lib/arc/client.ts`: viem `publicClient`
